Modes

One key changes the whole desktop.

Work, Play, Evening or your own. A mode swaps the wallpaper and accent, holds back notifications, opens its apps, adds shortcuts that exist only while it's on, and turns performance on for games.

It can come on by itself when a game starts, at an hour, on battery or with a monitor, and puts your windows back on their screen, workspace and column.

[[mode]]
name = "Play"
when = ["game"]   # Steam, Proton, Wine

[[mode]]
name = "Evening"
when = ["20:00-07:00", "battery"]
theme = "Night"

Coming from Hyprland

Bring your config with you.

It reads hyprland.lua in a sandbox where nothing runs, or hyprland.conf with the files it sources. Binds, screens, window rules, keyboard, touchpad, gaps, corners, the accent and autostart come over, with a note for every line.

What niri has no place for, like split layouts or submaps, is listed with why instead of quietly dropped.

vif
❯ apolline import hyprland --dry-run
Comes over (4)
  hyprland.conf:3    monitor DP-1 → [[display]] at 165 Hz
  hyprland.conf:14   bind SUPER, Q → close-window
  hyprland.conf:40   windowrule → pavucontrol floats
  hyprland.conf:52   exec-once → autostart
Stays behind (1)
  hyprland.conf:21   bind SUPER, J, togglesplit
                     niri has no split layouts

Nothing written: run it without --dry-run to bring this over.
The rest of the family

Live wallpapers, drawn natively.

Videos, Shadertoy shaders and Wallpaper Engine scenes from your Steam library, paused while you're locked or playing. Apolline runs them as its child, so decoding never lands inside the shell.

Install

One line on a fresh Arch.

It builds and sets up the whole desktop: niri, Apolline, vif, live wallpapers, sound, network, Bluetooth, the login screen, a file manager and fonts. Reboot and log in to niri.

{{}}

The script is short and worth a read first: install.sh. Already on Arch with niri? Install by hand with makepkg and apolline setup. Other distributions aren't packaged yet, but it builds with stable Rust.

Later on, apolline update brings the new release, and the bar tells you when there is one.
